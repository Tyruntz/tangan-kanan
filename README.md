# 🚀 tanganKanan.dev - Solusi Digital buat Bisnis Lokal

*Yo! Welcome to the repository of* **tanganKanan.dev**. 

Ini adalah *source code* buat *landing page* layanan digital (atau *freelance agency*) yang fokus ngebantu UMKM, *startup* tahap awal, dan *local business* buat *go digital*. Konsepnya *simple*: ngasih solusi tanpa bikin klien pusing sama *jargon* teknis yang ribet.

*Clean, fast, and straight to the point.*

## ✨ Features
- **Modern & Friendly UI:** Desain minimalis tapi *eye-catching*, pake font 'Plus Jakarta Sans' biar *vibe*-nya *techy* tapi tetep ramah.
- **100% Responsive:** Tampilan aman dan rapi mau dibuka lewat HP, tablet, ataupun *desktop*.
- **SEO & Social Share Ready:** Udah dipasang Meta Tags dan Open Graph. Jadi kalau lo *share* link-nya ke WhatsApp atau medsos, *thumbnail* dan deskripsinya bakal muncul dengan cakep.
- **Smooth Navigation:** Pake *vanilla script* buat *smooth scrolling* antar bagian. *No lag, just smooth transition.*

## 🛠️ Tech Stack
*Keep it lightweight!* Proyek ini sengaja nggak pake *framework overkill* karena emang didesain sebagai *static landing page* yang butuh kecepatan *load* maksimal.
- **HTML5** (Semantik & terstruktur)
- **CSS3** (Vanilla CSS dengan CSS Variables buat gampang ganti tema)
- **Vanilla JavaScript** (Cuma sejumput buat *handle smooth scroll*)

## 🚀 How to Run
Gak perlu pusing mikirin `npm install` atau *dependency* aneh-aneh. *It's basically plug-and-play*.
1. *Clone* repo ini ke mesin lo: 
   `git clone https://github.com/Tyruntz/tangan-kanan.git`
2. Buka foldernya.
3. Langsung *double-click* file `index.html` (atau paling enak *open with Live Server* kalau lo pake VS Code).
4. *Boom!* Web-nya langsung jalan di *browser*.

## 💡 Quick Customization
- **Ganti Tema:** Buka `style.css`, cari bagian `:root` di paling atas, terus ganti *hex code* warnanya sesuka hati lo.
- **Ganti Kontak WA:** Cari semua *link* yang depannya `https://wa.me/` di `index.html` dan ganti pake nomor lo yang aktif.
